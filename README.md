# HTML & CSS Practice Projects

A collection of beginner-friendly web development exercises built while learning **HTML, CSS, and basic JavaScript**. This repository documents my hands-on practice with common HTML elements, page structure, styling, forms, tables, lists, images, and simple browser interactions.

The projects are small and independent, making it easy to open each page and understand one concept at a time.

## 🧠 Concepts Practised

### HTML
- Basic document structure and page sections
- Headings, paragraphs, links, and images
- Ordered and nested lists
- Tables with headers, rows, and cells
- Forms and common input types
- Image maps and clickable image areas
- Navigation links and section IDs
- Semantic page elements such as `header`, `main`, `section`, and `footer`

### CSS
- Internal and external stylesheets
- Selectors and element styling
- Text alignment, colours, spacing, and padding
- Borders and border radius
- Background colours
- Hover effects
- Basic page layout and navigation styling

### JavaScript
- Variables and functions
- Button click events
- Reading and updating HTML elements through the DOM
- Basic arithmetic operations using a calculator

## 🚀 How to Run Locally

No installation or build tools are required.

1. Clone or download this repository:
   ```bash
   git clone https://github.com/RajaSuhashKesari/html-css-javascript-practice.git
   ```
2. Open the downloaded project folder.
3. Double-click any `.html` file, or open it in your preferred browser.
4. Keep related CSS and image files in their original locations so the pages can load their assets.
